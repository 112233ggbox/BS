# 自定义审批流程：人工实现清单

依据 assignment 第 3 页第 6 节，本模块实现不能使用 AI 辅助编程。本文件只记录需求和验收边界，不提供实现代码或算法伪代码。

人工工作范围：模板创建/编辑/启停界面；表单字段定义与动态填写；节点顺序及人员规则配置；发布校验；模板版本管理；员工使用启用模板提交第四类申请；该模块相关模型、迁移、接口、测试和前后端逻辑。

验收清单：

- 通过管理界面新建请假、用章或设备借用流程，过程不改代码或数据库。
- 支持单行文本、多行文本、数字/金额、日期、单选、附件，以及必填和必要校验。
- 模板包含名称、说明、适用部门、版本、启用状态。
- 不少于两个可排序的顺序节点，支持指定用户、申请人部门负责人规则。
- 字段标识唯一、条件引用有效、节点及人员规则完整、无循环。
- 新版本不改变已提交实例，停用后不可新建申请，历史仍可查询。
- 手机适配仅为基础体验；若争取移动提分，还须在所选小程序或独立 App 内完成本模块核心操作。

与其他模块的协作边界需由学生确定：身份与部门读取、附件授权、业务申请标识、具体人员快照、审批结果、通知事件。人工实现完成前，不由 AI 生成适配或替代代码。保留本人真实 Git 提交与演示证据。
